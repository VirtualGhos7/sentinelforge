# v0.1.0-alpha.1 — offline security workflow preview

Working offline MVP with fictional enterprise inventory, explainable risk, theoretical attack paths, scoped tools, exact human approval, simulated remediation and independent verification. Includes React analyst workspace, source-preserving public intelligence clients, optional mock-tested read-only live AI adapter and reproducible deterministic evaluation.

Validation: 46 Python tests passed, 88% aggregate coverage, one Chromium end-to-end workflow passed, TypeScript/build and Ruff passed, Bandit passed with the documented public fixture credential exception, and runtime/frontend dependency audits reported no known vulnerabilities. Linux CI passed Docker build and hardened Compose frontend/login/persisted-investigation smoke checks.

No API key was configured; live-model accuracy, token cost and unconstrained/hardened comparisons are unmeasured. This is not a production-ready enterprise platform. PostgreSQL normalization, production identities, real scanner verification, broader integrations, full lifecycle and model evaluations remain future work. See the README and docs/limitations.md.
